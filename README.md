### Olá, eu sou o Flavio Frois 👋

**Desenvolvedor | Especialista em Modernização de Sistemas Legados IBM i (AS-400)**

Sou apaixonado por resolver um dos maiores desafios do setor corporativo: **migrar sistemas legados críticos para arquiteturas modernas (Java 21 / Spring Boot / Cloud)** usando o poder da **Inteligência Artificial Local**.

---

### 🚀 O que estou construindo agora

**[Legacy AI Suite](https://github.com/froisf/legacy-ai-suite)** — Uma suíte de ferramentas de IA focada em privacidade de dados e preservação de contexto para tradução de RPGLE/DSPF para Java 21.

O diferencial? Usamos **Structured Chunking** (fatiamento semântico) em vez do *Naive Chunking*, garantindo que subrotinas (`BEGSR`), procedimentos (`DCL-PROC`) e telas (`DSPF`) sejam traduzidos como unidades lógicas completas — e **100% local**, sem enviar código sensível para a nuvem.
